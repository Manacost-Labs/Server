# JEV: рекомендации по модели и проверке задачи

Дополнение: [измерения сессии, факты, кэш справок, Probe и повторы](ECONOMY-WORKFLOW.md).

Пилот разрешён пользователем 2026-09-21 для улучшения экономии и качества.
`advise` рекомендует модель и глубину проверки один раз на ограниченную задачу.
Текущая модель всегда сохраняется. Автоматического переключения, циклов ревью,
проксирования сессий Codex и автоматического перехода на Sol/Astra нет.
Это собственный небольшой адаптер поверх существующего OpenRouter Decisions API,
а не установка полного jev-codex-router или jev-review.

## Начало задачи

В выбранном проекте создайте небольшой `task.json` с `goal`, `criteria` и
`constraints`. Только эти три поля разрешены; критерии должны быть непустыми.
История чата, код и локальные AGENTS.md не отправляются. Не включайте секреты
в описание: эвристическая проверка не гарантирует их обнаружения.

```bash
context-economy --project /path/to/project advise --task task.json \
  --category implementation --risk medium --selected-model terra --preview-remote

context-economy --project /path/to/project advise --task task.json \
  --category implementation --risk medium --selected-model terra \
  --allow-remote --daily-budget-usd 1
```

Укажите фактически выбранную модель (`luna|terra|sol|astra`). Категории:
`mechanical|documentation|implementation|debugging|architecture`; риск:
`low|medium|high|critical`. Категория и риск — сведения оператора, а не результат
независимого анализа. Политика проекта, авторизация пользователя и обязательные
проверки имеют приоритет перед рекомендацией JEV.

State ограничен 8 KB, запрос содержит две типизированные Choice-задачи.
Выбранная модель не отправляется, чтобы не подсказывать JEV желаемый ответ.
Provider, ключ и общий бюджет с `assist` остаются прежними: до $1 за скользящие
24 часа; без повторов HTTP, с timeout до 30 секунд. Кэш ответа — один час.
`request_cost_usd` означает стоимость именно текущего обращения: кэш — 0,
неизвестная цена/сбой — null. Исходные usage у кэшированного ответа не являются
новым расходом. Данный лимит не ограничивает остальные сервисы с тем же ключом.

Без `--allow-remote` сеть и ключи не используются. Локальная рекомендация —
сохранить модель и провести focused review, для high/critical — independent.
В shadow-режиме JEV может предложить `checks`, `focused` или `independent`.
Низкая уверенность (<0.8), uncertain или ошибка сохраняют локальный вариант;
порог является настройкой пилота, а не гарантией качества. High/critical никогда
не понижается ниже independent. Рекомендации стареют: при изменении задачи,
масштаба, риска или существенном новом факте запросите новую оценку. Это всё ещё
та же задача для счётчика пилота, а не новый успешный образец.

Один focused review после законченного изменения и одна проверка конкретных
исправлений обычно достаточны для пилота; выявленная проблема или требования
проекта могут потребовать дальнейшей работы. Не оптимизируйте балл JEV вместо
выполнения критериев. Поиск причин и подтверждение исправления остаются у агента.

## Финальный результат задачи

`advise` сохраняет приватную запись в SQLite проекта и возвращает `id`.
После фактических проверок запишите один итог, включая все попытки, подготовку
контекста и проверки. Пример структуры, значения нужно заменить измеренными:

```json
{
  "advice_id": "ID_FROM_ADVISE",
  "case_id": "parser-regression-issue-123",
  "variant": "advised",
  "dataset": "real",
  "model": "terra",
  "effort": "medium",
  "speed": "standard",
  "accepted": true,
  "checks_passed": true,
  "regressions": false,
  "attempts": 1,
  "rework_cycles": 0,
  "elapsed_seconds": null,
  "input_tokens": null,
  "output_tokens": null,
  "cached_input_tokens": null,
  "reasoning_tokens": null,
  "api_cost_usd": null,
  "codex_credits": null,
  "evidence": "Actual commands, results and remaining limitations"
}
```

```bash
context-economy --project /path/to/project pilot-record --file outcome.json
context-economy --project /path/to/project pilot-report
```

`accepted` означает выполнение критериев по оценке оператора, не фиктивное
подтверждение пользователя. `regressions=false` означает отсутствие известных
регрессий в пределах описанных проверок. Это самоотчёт, не независимый аудит.
Сохраняйте реальные effort/speed или `unknown`; никогда не угадывайте их.
Для смешанных моделей разбейте работу на сравнимые фазы или используйте
существующие `record`/`report --end-to-end` для отдельных попыток.

`api_cost_usd` — общий измеренный API-расход задачи, включая JEV/Gemma, прочую
подготовку, ревью и неуспешные попытки. Автоматически сохранённая цена рекомендации
показана отдельно и не прибавляется к этому итогу второй раз. `codex_credits`
принимает только фактическое измерение; цены API и сокращение текста не дают
формулы пересчёта в лимит подписки. Cached tokens уже входят в input, reasoning
tokens — в output. Неизвестное значение остаётся null, а не нулём.

Цель наблюдения — 10–20 реальных задач. Синтетические прогоны записываются с
`dataset=synthetic` и видны только в `pilot-report --dataset synthetic`.
У одной пары (dataset, case_id) разрешено по одному итоговому результату
`baseline` и `advised`; повторное добавление отклоняется. Для сопоставления
требуются одинаковые категория и хеш файла задачи. Не запускайте дорогую
повторную задачу только ради baseline: используйте сравнимые уже нужные работы
или отдельно согласованный контролируемый эксперимент. Совпадение описания не
доказывает равную сложность, одинаковые исходные условия или причинность.

Отчёт показывает качество, попытки, переделки, настройки моделей и измеренные
парные расходы. Неизвестные метрики исключаются только из соответствующего
парного показателя с явным числом измеренных пар. Неуспешные результаты не
исключаются ради красивой экономии. Никакое количество записей не включает
автомаршрутизацию: решение по конкретной категории остаётся отдельным.

## Проверки и откат

Тесты `tests/test_advisor.py`: отсутствие сети по умолчанию/preview, неизменность
модели, граница риска, валидация ответов, кэш без повторной оплаты, сбои и устаревшая
задача, секреты/размер, дубликаты, неизвестные расходы, регрессии качества,
разделение synthetic/real и CLI. Они включены в `make verify`.

Проверено 2026-09-21: 15 новых тестов, 16 тестов remote-assist, 9 тестов
ai-memory и полный `make verify` прошли. Живой синтетический запрос о простой
правке README вернул Luna/checks, сохранив выбранную Terra. Стоимость запроса
$0.000029232, время около 0.57 секунды. Повтор пришёл из кэша, цена текущего
обращения 0. Эта проверка подтверждает работу API и ограничений, но не качество
реального изменения кода и не экономию подписки. Реальные итоги нельзя подменять
синтетической проверкой; на момент установки сравнительная выборка ещё не собрана.

Установка заменяет только symlink версии context-economy после проверок.
Для отката верните предыдущую версию `~/.local/share/codex-context-economy/current`.
Приватные таблицы advice/pilot_outcomes аддитивные; память, API-ключ и ai-memory
не меняются. Старый runtime игнорирует новые таблицы.
