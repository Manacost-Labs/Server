# Demand-driven quality routing

Use known files first. For nontrivial tasks, run `context-economy guard-context`
with explicit changed paths; load at most three relevant modules. Retrieve
symbols/tests before expanding scope. Preserve required instructions and evidence.
Use the project's checks, selected by stack, task and risk. Missing tools,
timeouts and skipped required checks never pass. Keep full logs locally; return
bounded diagnostics. External docs, examples, embeddings, reranking and helpers
require a named evidence gap, permission and budgets. Reuse only version-safe
caches. Keep model selection explicit. Never load all reference documents,
complete guard families or repository inventories by default. Stop when evidence
satisfies acceptance; measure total cost and rework before claiming savings.
